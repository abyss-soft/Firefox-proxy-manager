Простой прокси для определенных сайтов, без рекламы.

Управляйте прокси по списку доменов: направляйте через прокси только выбранные сайты или включите прокси для всех сайтов, кроме исключений.

Proxy Manager позволяет настроить адрес прокси и выбрать, для каких доменов он будет использоваться. В обычном режиме прокси применяется только к сайтам из основного списка. В режиме исключений прокси применяется ко всем сайтам, кроме доменов в списке исключений. Списки можно импортировать и экспортировать.

# Установка и использование Proxy Manager

Версия для Google Chrome: [Chrome Proxy Manager](https://github.com/abyss-soft/Chrome-proxy-manager)

## Шаг 1: Скачать расширение с GitHub

1. Скачайте (https://github.com/abyss-soft/Firefox-proxy-manager) репозиторий
2. Распакуйте загруженный архив в удобное место на компьютере
3. Создайте **zip-архив** этого репозитория

## Шаг 2: Включение режима разработчика в Firefox Developer (только в нем можно устанавливать обновления из локального файла)

1. Откройте браузер Firefox

2. Перейдите на страницу **Управление расширениями**, набрав в адресной строке: `about:addons`

## Шаг 3: Установка распакованного расширения

1. Нажмите на кнопку **Установка дополнений из файла** (выберите zip-архив расширения).
2. Firefox загрузит расширение, и оно появится в списке установленных расширений.

## Шаг 4: Использование расширения

1. Нажмите на иконку вашего расширения в панели инструментов Firefox.

2. В интерфейсе расширения вы можете:

- Включить/выключить прокси.

- В обычном режиме через прокси идут только сайты из основного списка, остальные открываются напрямую. Добавляйте домен без протокола и пути, например `example.com` или `www.example.com`.

- Если включить режим исключений, через прокси идут все сайты, кроме перечисленных в списке исключений. Режим исключений доступен при включенной активации прокси.

- Настроить параметры прокси-сервера в формате `схема://хост:порт` и нажать «Сохранить».

3. Списки и переключатели сохраняются автоматически. Адрес прокси сохраняется после нажатия «Сохранить» и применяется при включенной активации прокси.

## Шаг 5: Обновление расширения (при выходе новой версии)

Когда в GitHub появится новая версия, скачайте и распакуйте её, как описано выше.

Теперь расширение установлено и готово к использованию!
